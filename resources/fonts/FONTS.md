# Bundled Fonts & Licensing

This directory contains self-hosted web font assets (WOFF2) for the offline desktop client, matching the **Master Duel / Modern Gaming UI** aesthetic.

## Included Font Families

### 1. Oxanium (Display, Headers, Buttons & Tabular LP Counters)

- **Author/Designer:** Severin Meyer
- **License:** SIL Open Font License, Version 1.1 (`OFL.txt`)
- **Usage:** Game screen titles, menu buttons, modal headers, victory banners, duel HUD banners, and tabular numerals (`font-variant-numeric: tabular-nums`) for Life Point and ATK/DEF counters.
- **Files:**
  - `Oxanium-Regular.woff2` (Weight 400)
  - `Oxanium-Medium.woff2` (Weight 500)
  - `Oxanium-SemiBold.woff2` (Weight 600)
  - `Oxanium-Bold.woff2` (Weight 700)
  - `Oxanium-ExtraBold.woff2` (Weight 800)

### 2. Barlow Semi Condensed (Card Rules, Body & UI)

- **Author/Designer:** Jeremy Tribby
- **License:** SIL Open Font License, Version 1.1 (`OFL.txt`)
- **Usage:** Card rules text, card lore, dialog messages, guidance banners, filter bars, and tooltips.
- **Files:**
  - `BarlowSemiCondensed-Regular.woff2` (Weight 400)
  - `BarlowSemiCondensed-Medium.woff2` (Weight 500)
  - `BarlowSemiCondensed-SemiBold.woff2` (Weight 600)
  - `BarlowSemiCondensed-Bold.woff2` (Weight 700)

### 3. Cinzel & Inter (Fallbacks)

- **License:** SIL Open Font License, Version 1.1 (`OFL.txt`)
- **Files:** `Cinzel-*.woff2`, `Inter-*.woff2`
